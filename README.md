## **Описание предметной области**
Приложение для гостиницы с авторизацией для входа, введением CAPTCHA для защиты и после входа переходом на главную форму.

*Функционал:*
* Авторизация с полями ввода логин/пароль.
* CAPTHA для защиты.
* Главная форма с информацией об авторе.
